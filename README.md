# Tic Tac Toe Game

## Project Overview
Tic Tac Toe is an interactive game developed using Java. It allows two players to play the classic Tic Tac Toe game by taking turns marking spaces on a 3×3 grid.

## Features
- Interactive game interface.
- Two-player gameplay.
- Automatic winner detection.
- Draw detection.
- Simple and user-friendly gameplay.

## Technologies Used
- **Java** – Programming language.
- **JAR** – Executable application file.

## Project Files
- Java source code – Contains the game implementation.
- JAR file – Executable version of the game.
- Project Presentation – Provides an overview of the project.

## How to Run
1. Make sure Java is installed on your computer.
2. Download the JAR file from this repository.
3. Open the terminal in the downloaded file's location.
4. Run the following command:

```bash
java -jar TicTacToe.jar
```
